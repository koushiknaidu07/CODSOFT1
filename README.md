# The Indian Ocean – Music Band Landing Page

A simple, visually focused music band landing page created using **HTML and CSS**. The page presents a band-themed design with a navigation menu, introductory content, background imagery, and music platform icons.

## Project Overview

This project demonstrates the fundamentals of front-end web development by creating a static landing page for a music band.

## Features

- Navigation menu with sections such as Music, Band, Tour, Journal, Shop, and Newsletter
- Full-page background image
- Introductory welcome section
- Call-to-action button
- Music platform icons for Spotify, Apple Music, SoundCloud, and Deezer
- Custom styling using CSS

## Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Layout, styling, and background presentation
- **Font Awesome** – Music platform icons

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `main.html`, `style.css`, and `123.jpg` are in the same directory.
4. Open `main.html` in your web browser.

No additional installation is required.
